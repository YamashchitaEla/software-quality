## Test Design

### calculateDiscount

Test conditions:
- TCND-01 - розрахунок стандартної позитивної знижки (еквівалентне значення всередині норми);
- TCND-02 - розрахунок граничного випадку мінімальної знижки (0%);
- TCND-03 - розрахунок граничного випадку максимальної знижки (100%);
- TCND-04 - перевірка реакції на некоректне від'ємне значення ціни;
- TCND-05 - перевірка реакції на некоректне значення відсотка знижки (менше 0%);

Test Data:
1. price = 100, percent = 10 (Очікується: 90)
2. price = 100, percent = 0 (Очікується: 100)
3. price = 100, percent = 100 (Очікується: 0)
4. price = -10, percent = 10 (Очікується помилка: 'Price must be a non-negative number')
5. price = 100, percent = -10 (Очікується помилка: 'Discount must be between 0 and 100')

### getShippingCost

1. Гілка платна доставка: Коли сума замовлення позитивна, але менша за поріг безкоштовної доставки (0 <= total < 1000). Повертається вартість 100.
2. Гілка безкоштовна доставка: Коли сума замовлення дорівнює або перевищує поріг безкоштовної доставки (total >= 1000). Повертається 0.
3. Гілка помилки: Коли сума замовлення менша за нуль (total < 0). Викидається виключення 'Total must be a non-negative number'.
